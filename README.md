# Hive-ChatRoom
A type of chat room that uses a Raspberry Pi Pico paired with an ESP-01S Wi-Fi module as the backend server; it can be used on a local network by up to 8 devices simultaneously.
I developed this code during the 88-day widespread internet blackout in Iran to eliminate the need for government-based applications which offer near-zero privacy. It can be used to sync the clipboard across multiple devices or to exchange short messages among family members.
