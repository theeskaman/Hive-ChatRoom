# HIVE chatroom

HIVE chatroom is a local-network chatroom built around a Raspberry Pi Pico paired with an ESP-01S Wi-Fi module. The project is intended to support up to 8 devices on the same local network, including short-message exchange and clipboard synchronization.

## Repository layout

- `main`: project overview and the repository's current baseline. Early uploaded version files have been moved off this branch to keep it uncluttered.
- [`initial-versions`](https://github.com/theeskaman/Hive-ChatRoom/tree/initial-versions): archive of the early uploaded versions, organized by version under `versions/`.
